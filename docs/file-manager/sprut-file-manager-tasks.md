- **SPRUT-1. Создание каркаса приложения.** Создать Maven-проект, Spring MVC, обработку ошибок и health checks.

- **SPRUT-2. Подключение инфраструктуры из YAML.** Подключить одну общую конфигурацию MinIO и одну OpenSearch для всех пространств. Проверять настройки и размещение; выбора подключения в API и админке нет.

- **SPRUT-3. Интеграционное тестовое окружение.** Настроить PostgreSQL и MinIO для интеграционных тестов, включая конкурентные запросы, потерю ответа и падение обработчика.

- **SPRUT-4. Миграции PostgreSQL и генерация jOOQ.** Реализовать Liquibase-миграции, расширение ltree, fs_node.tree_path только для папок, ограничения согласованности с parent_id, GiST/B-tree индексы и генерацию jOOQ. Сначала создать 17 таблиц базовых файловых сценариев, остальные добавлять по мере реализации функций; историю записывать с первого изменения.

- **SPRUT-5. Проверка вызывающего сервиса и доступа к файлам.** Настроить mTLS через SSL bundles с возможностью отключения в локальном профиле. Пользовательские X-Actor-* принимать только от доверенного gateway, tenantId брать из YAML. Проверять роли и ACL в бизнес-логике операций с файлами и папками. Для MVC включить CSRF-защиту; передавать correlation/trace-контекст.

- **SPRUT-6. Общие механизмы изменения состояния.** Реализовать идемпотентность, CAS, блокировки пространства и атомарную запись изменений, истории, аудита и заданий индексации.

- **SPRUT-7. `POST /api/v1/retention-policies`.** Создавать политику хранения версий, истории и служебных данных.

- **SPRUT-8. `GET /api/v1/retention-policies`.** Возвращать доступные политики хранения.

- **SPRUT-9. `POST /api/v1/spaces`.** Создавать пространство, корневую папку и начальные права доступа.

- **SPRUT-10. `GET /api/v1/spaces`.** Возвращать список доступных пространств с пагинацией.

- **SPRUT-11. `GET /api/v1/spaces/{spaceId}`.** Возвращать сведения об одном пространстве с проверкой доступа.

- **SPRUT-12. `POST /api/v1/spaces/{spaceId}/nodes`.** Создавать папку с tree_path от родителя или файловый узел с tree_path=NULL без опубликованного содержимого.

- **SPRUT-13. `GET /api/v1/nodes/{nodeId}`.** Возвращать сведения о файле или папке, включая маркеры и текущую версию содержимого.

- **SPRUT-14. `GET /api/v1/nodes/{nodeId}/children`.** Возвращать содержимое папки с пагинацией, фильтрами и проверкой доступа; subtree выбирать через ltree папок и JOIN родителя файлов, без полного Recursive CTE.

- **SPRUT-15. `GET /api/v1/nodes/{nodeId}/ancestors`.** Возвращать цепочку предков по UUID-меткам tree_path от корня до родителя выбранного узла с проверкой структуры и доступа.

- **SPRUT-16. `GET /api/v1/spaces/{spaceId}/nodes/resolve`.** Находить файл или папку по логическому пути внутри пространства.

- **SPRUT-17. `POST /api/v1/spaces/{spaceId}/uploads`.** Создавать сессию загрузки нового файла или обновления существующего с фиксацией исходной версии.

- **SPRUT-18. `GET /api/v1/uploads/{uploadId}`.** Возвращать состояние сессии, текущей попытки, прогресс передачи и опубликованный результат.

- **SPRUT-19. Очистка незавершённых загрузок.** Реализовать фоновый воркер отмены незавершённых multipart и удаления неопубликованных объектов через gc_task с проверкой ссылок и защитных удержаний.

- **SPRUT-20. Восстановление и истечение upload sessions/attempts.** Реализовать фоновый воркер обработки истёкших сессий и leases. Запрещать публикацию старой попытки и ставить её данные на очистку.

- **SPRUT-21. `PUT /api/v1/uploads/{uploadId}/content`.** Принимать файл потоково в MinIO, контролировать размер и сохранять прогресс. Каждой попытке выделять отдельный object key.

- **SPRUT-22. Фоновая проверка загруженного содержимого.** Реализовать фоновый воркер проверки размера и SHA-256 загруженного объекта с сохранением результата проверки.

- **SPRUT-23. `POST /api/v1/uploads/{uploadId}/complete`.** Публиковать проверенную версию файла атомарно с указателем текущей версии, историей и аудитом. Повтор возвращает исходный результат.

- **SPRUT-24. `DELETE /api/v1/uploads/{uploadId}`.** Отменять неопубликованную загрузку и ставить её данные на очистку. Опубликованный файл сохраняется.

- **SPRUT-25. `GET /api/v1/nodes/{nodeId}/content`.** Передавать содержимое выбранной версии потоком с поддержкой Range, условных запросов и защиты от удаления во время чтения.

- **SPRUT-26. `HEAD /api/v1/nodes/{nodeId}/content`.** Возвращать заголовки выбранной версии без передачи содержимого.

- **SPRUT-27. `POST /api/v1/nodes/{nodeId}/move`.** Перемещать узел внутри пространства с проверкой прав, версии, циклов и конфликта имён. Атомарно обновлять tree_path вложенных папок при смене родителя, проверять maxAtomicMoveFolders; не менять nodeId и S3 object key.

- **SPRUT-28. Загрузка дерева папок.** Реализовать клиентскую загрузку дерева через существующие API: создание родителей, ограниченную параллельность, прогресс, журнал повторов и отмену с сохранением частичного результата.

- **SPRUT-29. MVC создания пространств.** Создать MVC-форму ввода имени, политики хранения и начальных прав. Настройки MinIO/OpenSearch берутся из общего YAML.

- **SPRUT-30. MVC ролей и ACL.** Создать MVC-интерфейс управления локальными ролями и правами на папки и файлы.

- **SPRUT-31. Retention версий и истории.** Реализовать фоновый воркер очистки старых версий и истории по политике хранения с учётом текущих версий, ссылок и защитных удержаний.

- **SPRUT-32. Retention служебных данных.** Реализовать фоновый воркер очистки аудита, завершённых заданий и записей идемпотентности с сохранением обязательных сроков хранения.

- **SPRUT-33. Индексация OpenSearch.** Реализовать фоновый воркер индексации OpenSearch: обработку заданий узлов и поддеревьев, пакетный обход, повторные попытки и проверку актуальности revision.

- **SPRUT-34. Discovery массовых операций.** Реализовать фоновый воркер пакетного обхода корней массовых операций с сохранением состава работ, cursors и зависимостей.

- **SPRUT-35. Исполнение массовых операций.** Реализовать фоновые обработчики корректора, копирования, удаления, восстановления и компенсаций с поддержкой отмены, CAS и частичного результата. COPY/restore/rollback должны поддерживать актуальные tree_path и лимит атомарного перемещения.

- **SPRUT-36. Формирование ZIP.** Реализовать фоновый воркер сборки ZIP с сохранением manifest, повторными попытками, публикацией готового архива и очисткой по TTL.
